## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/MrShadowRIFAT/NextJS_Cinematic_Portfolio.git
cd NextJS_Cinematic_Portfolio
```

### Install & Run (Node.js)

```bash
npm install
npm run dev
```
